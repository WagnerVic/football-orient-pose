# Backlog (decisões adiadas)

Esta pasta registra **trabalho conscientemente adiado** — itens que fazem sentido, mas foram
despriorizados por um bloqueio (custo, dependência, dado faltando). Cada doc explica **o quê**, **por
que adiamos**, **o que é preciso para retomar** e as **alternativas** consideradas.

Não é "descartado": é "parado de propósito, com o caminho de volta documentado".
